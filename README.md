## 🤖 mikoO چیست؟ | What is mikoO?

**mikoO AI Studio** یک محیط دسکتاپ یکپارچه برای تعامل با هوش مصنوعی‌های پیشرفته است. ساخته شده با Electron + React + TypeScript، این اپلیکیشن تجربه‌ای متفاوت از کار با AI را ارائه می‌دهد.

> *A powerful, fully-customizable AI desktop client built for developers, creators, and curious minds — by a high school student.*

## ✨ Features | قابلیت‌ها

### 🧠 AI Integration
| Feature | Description |
|---------|-------------|
| Multi-Model Support | GPT-4o, GPT-4o Mini, Claude 3.5 Sonnet, Claude 3 Haiku |
| Real-Time Model Switching | Switch AI provider mid-conversation |
| Image Generation | DALL-E 3 via `/image` command |

| Feature | Description |
|---------|-------------|

## 🚀 Getting Started

### Prerequisites
- Node.js `>= 18`
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/mikailardeshir-hub/mikoo.git
cd mikoo

# Install dependencies
npm install

# Start in development mode
npm run dev

# Build for production (Windows)
npm run build:electron
```

### Configuration
1. Open **mikoO** → **Settings** → **API & Config**
2. Enter your **OpenAI API Key** for GPT-4o access
3. *(Optional)* Enter your **Anthropic API Key** for Claude
4. Start chatting! 🎉
