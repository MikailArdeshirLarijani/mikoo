## 🌟 Overview | درباره پروژه

**mikoO IDE** is an **AI-first code editor** and passion project developed by **Mikail Ardeshir**. Like modern AI editors such as **Cursor**, it is built on top of the world-class open-source foundation of **VS Code (Code-OSS)**, embedding a native **mikoO AI Copilot** and an integrated **Personalization Studio** directly into the core editor workflow.

> *💡 **Project Philosophy**: Rather than reinventing text buffers and language servers from scratch, mikoO IDE harnesses the proven VS Code engine while fundamentally transforming the developer experience with native generative intelligence and visual customizability.*

---

## ⚔️ Key Differences: mikoO IDE vs Regular VS Code

What makes **mikoO IDE** distinct from standard Visual Studio Code?

| Feature | Standard VS Code | mikoO IDE |
| :--- | :---: | :---: |
| **Native AI Copilot** | ❌ Requires separate paid extensions / logins | ✅ **Built directly into the Activity Bar out-of-the-box** |
| **Context Ingestion** | ❌ Manual copy-pasting required | ✅ **One-click `Attach Active File` button** |
| **Instant Tab Extraction** | ❌ Copy, create new file, paste | ✅ **`Open in New Tab` creates an editor buffer immediately** |
| **In-Place Cursor Injection** | ❌ Manual clipboard paste | ✅ **Direct `Insert` button injects at cursor position** |
| **Token & Cost Counter** | ❌ Not available | ✅ **Live real-time token counter & estimated API cost ($)** |
| **Visual Customizer Studio** | ❌ Edit raw `settings.json` manually | ✅ **Dedicated UI tab for colors, fonts, radius & canvas** |
| **Telemetry & Privacy** | ⚠️ Microsoft telemetry enabled by default | ✅ **Clean Code-OSS core with zero Microsoft telemetry** |
| **Multi-Model Switching** | ❌ Tied to vendor plugins | ✅ **Direct instant toggle between GPT-4o, Mini & Claude** |

## 🛠️ Architecture & Core Features

### 1. The VS Code Core
* **Full Language Diagnostics**: Rich syntax highlighting, auto-complete, and IntelliSense for TypeScript, JavaScript, Python, C++, Go, Rust, and more.
* **Integrated Terminals**: Native PowerShell, Command Prompt, Git Bash, and WSL sessions.
* **Extension Compatibility**: Compatible with open-source VS Code extensions.

### 2. Built-in mikoO AI Copilot
* **Bi-directional Editor Bridge**: Can read from your active text editor and write code directly back into your files.
* **Quick Task Chips**: Rapid triggers for `Explain Code`, `Find Bugs & Optimize`, and `Unit Tests`.
* **Zero Overhead**: Native VS Code UI styling (`var(--vscode-*)`) ensures the assistant feels completely integrated and lightweight.

### 3. Integrated Personalization Studio
* **Accent Tones**: Fast switching between Cobalt Blue, Neon Cyan, Purple, Emerald, and Rose.
* **Canvas Wallpapers**: Choose from *Default Dark*, *Subtle Grid*, *Matrix Minimal*, or *Deep Space*.
* **Typography Controls**: Real-time font size and corner radius sliders.

## 🚀 Getting Started

### Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/MikailArdeshirLarijani/mikoo.git
   ```
2. Launch **mikoO IDE** via the desktop shortcut or executable.
3. Open any project folder (`File` → `Open Folder...`).
4. Click the **mikoO AI** icon in the left Activity Bar to begin pair programming!
